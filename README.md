# 时间推进器 · Chronos Driver

一个适用于 **SillyTavern 1.12+** 的第三方前端扩展：维护一条**剧情时钟**，让你用「一天后」「3 小时」「明天早上」这样的说法直接推进剧情时间，并让 AI 生成过渡与新场景。

和「忒修斯神器」同一套结构、同一套配色。

## 功能

- **剧情时钟**：面板顶部显示当前剧情时间（如「第 3 天 20:15」），每次推进后自动累加；也可以随时手动校准。
- **自然语言推进**：输入框里怎么写都行，认得出这些形式 ——
  | 写法 | 效果 |
  |---|---|
  | `一天后` / `1天后` | 推进 1 天 |
  | `3 小时` / `二十小时后` | 推进对应时长 |
  | `半小时` / `两个小时` | 同上 |
  | `两天半` | 推进 2.5 天 |
  | `1 天 3 小时` | 连写会相加 |
  | `明天早上` / `后天晚上` / `次日中午` | 跳到目标那天的指定时段 |
  | `早上` / `傍晚` | 取下一个该时刻（今天还没到就是今天） |
  | `三天前` / `回到一周前` | 往回推 |
- **三种生成方式**：过渡 + 新场景（默认）／直接切到新场景／只写过渡小结。
- **两种记录方式**：插一条系统消息（默认，不干扰对话）或用户消息。
- **撤销上次**：把剧情时钟退回上一次推进之前（已生成的消息不会删除）。
- **斜杠命令**：在聊天输入框直接打 `/t 一天后`，不用打开面板。
- **浮窗**：可从设置页弹出为浮窗。

## 安装

1. 把整个 `时间推进器` 文件夹放进 `SillyTavern/public/scripts/extensions/third-party/`，形成 `.../third-party/时间推进器/manifest.json`。
2. 重启 SillyTavern 或刷新浏览器，在扩展面板启用「时间推进器」。

也可以用酒馆的 **URL 安装**，直接填 `https://github.com/xiongwang920-oss/chronos-driver`。`manifest.json` 里开了 `auto_update: true`，这种方式装的话以后会自动更新（要求机器能访问 GitHub）。

## 用法

**面板**：在「推进时间」里选一个快捷项，或者直接输入，点「推进剧情」。

**斜杠命令**：`/t 一天后`、`/t 3小时`、`/t 明天早上`。别名 `/timeskip`、`/推进`。

推进时插件会做三件事：

1. 把剧情时钟推进到目标时间；
2. 往聊天里插入一条指令消息（默认是系统消息，显示为灰色，不会干扰角色对话）；
3. 触发一次生成，让 AI 按你选的「生成方式」写出这段时间的过渡与新场景。

## 换聊天时注意

剧情时钟是全局保存的，**切换聊天或角色卡时不会自动重置**——因为剧情可能跨聊天连续。如果新剧情的时间线和旧的对不上，到「校准时钟」里把「第几天 / 时 / 分」改好再点保存即可。

## 已知限制

- 时间解析是**本地规则匹配**，不是模型理解。`下周三`、`等我洗完澡` 这类相对表达认不出来，此时插件会**明确报错**而不是猜——因为剧情时间偷偷跑偏比报错更麻烦。遇到认不出的写法，换成 `3天后`、`明天早上` 这种即可。
- 一个月按 30 天、一年按 365 天计算。
- 触发生成依赖酒馆的 `Generate` 接口。如果你的版本没有这个接口，插件会提示「消息已插入，请手动点发送」——指令消息本身已经写进聊天，手动发送一样能生效。
